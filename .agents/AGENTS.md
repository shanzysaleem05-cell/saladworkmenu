# SaladWorks Project Rules

## Formatting Constraints
- **NO EM-DASHES**: NEVER use the em-dash character (`—`) anywhere in this project's code, content, JSON data, or markdown files. Always use a standard hyphen (`-`) instead for displaying time ranges, prices, or separators (e.g., use `10:00 AM - 9:00 PM` instead of `10:00 AM — 9:00 PM`).
